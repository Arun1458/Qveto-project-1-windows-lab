# M3 Audit Test Cases & Execution Standards

**Role:** Vulnerability Assessment Analyst (M3)  
**Target Environment:** `windows11-lab` (`10.10.10.20/24`)  

## 1. Folder Purpose
This directory houses the standardized, approved test cases used by the M3 role to identify vulnerabilities and misconfigurations on the Windows 11 target. It ensures all audits are repeatable, documented, and strictly adhere to the project's non-destructive Rules of Engagement.

## 2. Test Case Structure
Each test case in this directory (`m3-audit-test-cases.md`) includes:
* **Objective:** The specific misconfiguration being targeted (e.g., Unquoted Service Paths, Weak Registry ACLs).
* **Prerequisites:** Required user context (e.g., standard user `LABWIN`) and network conditions.
* **Approved Steps:** The exact, read-only Windows administrative commands executed.
* **Expected Telemetry:** The anticipated event logs (Sysmon/Windows Event Viewer) generated by the command, coordinated with M5.

## 3. Retesting Phase (Week 4)
During Week 4, these exact same test cases will be re-executed against the VM after M6 applies remediation patches. The goal is to verify that the security control now behaves defensively (e.g., blocking access or removing the vulnerability) without breaking baseline functionality.
