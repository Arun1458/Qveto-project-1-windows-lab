# Rules of Engagement — Week 1

Project: Windows Exploitation & Privilege Escalation Lab  
Date: 18-10-2026  
Prepared by: dhruv-sain-hub

## 1. Purpose

Establish the scope and safety requirements for the virtualization and network isolation phase of the project.

## 2. Authorized Systems

Only the following VMs are in scope:

### Windows 11 Target

- VM name: windows11-lab
- IPv4 address: 10.10.10.20/24
- Role: Lab target

### Kali Linux Testing VM

- VM name: kali-linux-2026.2-virtualbox-amd64
- IPv4 address: 10.10.10.10/24
- Role: Testing and network verification

## 3. Authorized Activities

- Inspecting VirtualBox VM settings.
- Recording CPU, RAM, and virtual disk capacity.
- Configuring the Internal Network LabNet.
- Verifying IP addressing and routes.
- Testing ICMP connectivity between the two authorized VMs.
- Reviewing network adapter and isolation settings.
- Creating and verifying recovery snapshots.
- Capturing sanitized configuration evidence.

## 4. Prohibited Activities

- Testing systems outside the authorized lab.
- Scanning public IP addresses or unrelated devices.
- Accessing systems without explicit authorization.
- Connecting the lab to external networks without reviewing and approving the change.
- Disabling host security controls.
- Uploading VM disks, installation ISOs, passwords, private keys, or access tokens to GitHub.

## 5. Network Requirements

- Both VMs must use Internal Network LabNet for the lab.
- Bridged networking is not intended.
- Additional network adapters require review before use.
- The lab interfaces should not have a default gateway or DNS configuration unless the approved design changes.
- Firewall protections must remain enabled.
- Only the specific inbound rule required for the authorized ping test was enabled.

## 6. Recovery and Documentation

- Verify baseline snapshots before higher-risk changes.
- Record all configuration changes.
- Document unexpected behavior and recovery steps.
- Remove sensitive information from screenshots before sharing.
- Commit documentation to the designated feature branch.

## 7. Scope Changes

Any change to the authorized VMs, network configuration, or permitted activities must be reviewed and documented before proceeding.

## 8. Completion Criteria

Week 1 is ready for review when the VM inventory, network design, connectivity results, isolation review, and required evidence are documented.

End of rules of engagement.
